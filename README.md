# Schrödinger's Cat Petting Simulator

Tired of opening a box to see if Schrödinger's cat is dead or alive? Wait no more!
With this React simulation, you explore the probability and convergence of petting
one of two very cute cats. 

Not optimised for mobile!

## Features

- Random petting simulation (50/50 or adjustable probability)
- Live statistics tracking
- Convergence graph showing long-term behavior
- Interactive probability slider

## Tech Stack

- React
- JavaScript
- CSS

## How to run

npm install  
npm start
